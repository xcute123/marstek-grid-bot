MARSTEK GRID BOT — ФУНКЦИОНАЛ
==============================

Telegram-бот + Mini App для мониторинга батарей Marstek (Venus E и др.).
Следит за сетью (свет есть / нет), показывает мощности в реальном времени,
предупреждает об опасных ситуациях. Запуск: start_bot.bat

1. КАК ЭТО РАБОТАЕТ
-------------------
- Облако Marstek (eu.hamedata.com): список устройств, статус, заряд. Опрос раз в
  POLL_SEC секунд (по умолчанию 180). Для Venus E 3.0 облако не отдаёт мощности (нули).
- MQTT (тот же канал, что у официального приложения): живые кадры от батареи
  (заряд, мощность батареи, сеть, EPS, Wi-Fi, статус, счётчики). Одно постоянное
  соединение, ответ батареи примерно раз в 2,5 с в быстром режиме.
  Нужны сертификаты в mqtt_certs/ (см. tools/pull_certs.py).
- Определение «сети нет»: рабочий статус батареи 4 = резерв (EPS) = света нет.
  Свежий MQTT-кадр важнее облачного статуса (он отстаёт).
- «Связь потеряна»: если MQTT-кадров нет дольше заданного времени — это НЕ считается
  пропажей сети, а отдельным событием.
- Время везде по Киеву (Europe/Kyiv), переход на зимнее время учитывается.


2. БОТ: ЭКРАНЫ И КНОПКИ
-----------------------
Главное меню (/start, /menu, /status, /help)
  - список устройств: значок состояния, «Сеть есть/Нет сети (сколько длится)»,
    заряд, мощности
  - 📱 Приложение — открыть Mini App
  - 🔄 Обновить, ⚙️ Аккаунты, 🛡 Админ (для админа, с числом заявок)
  - 👁 рядом с устройством — устройство, которым с вами поделились

Экран устройства
  - состояние сети и причина, прогноз работы от батареи (когда сети нет)
  - телеметрия (живая или из облака), возраст данных
  - 📡 LIVE в чате, 📱 Приложение
  - 🔄 Обновить, 🧪 Тест пуша
  - режим детекции: Авто / Online / Grid Вт
  - ёмкость: 2.56 / 5.12 / 10.24 / 15.36 кВт·ч
  - 🔔/🔕 пуши, ⚙️ Поля (какие показания видны)
  - 📊 Статистика отключений (24 ч / 7 / 30 дней)
  - 🔔 Настройки алертов
  - 👥 Поделиться, 🗑 Удалить (с подтверждением)
  У зрителя (с кем поделились) только: LIVE, Приложение, Обновить, Статистика,
  «Мои уведомления».

Статистика отключений
  - число, суммарное время без света, самое долгое, среднее, % времени со светом,
    последние отключения (начало → конец, заряд на старте и на конце)

Аккаунты: добавить аккаунт Marstek (email + пароль; пароль хранится как MD5,
  сообщение с паролем сразу удаляется из чата), выбрать регион (Европа/Глобал),
  обновить, удалить.

Админ-панель: заявки на доступ (✅/⛔), список пользователей, удаление, добавление по ID.


3. УВЕДОМЛЕНИЯ (АЛЕРТЫ)
-----------------------
Получает владелец и зрители, у которых включены уведомления.
  🔴 СЕТЬ ПРОПАЛА / 🟢 СЕТЬ ПОЯВИЛАСЬ — сколько света не было / было, заряд,
     прогноз «хватит на ~Х ч (до ≈ЧЧ:ММ)»
  🪫 Низкий заряд при отсутствии сети — пороги по умолчанию 30 / 15 / 10 %,
     каждый порог один раз за отключение; свои пороги настраиваются
  🔋 «Батарея заряжена до 100%» — после возвращения света
  ⚠️ Перегрузка — отдача ≥ порога (80/90/95 %) от предела; предел берётся у батареи
     или задаётся вручную (300…10000 Вт)
  📵 Связь с батареей потеряна / 📶 восстановлена — через 2/4/10/30 мин молчания
  🔎 Аномалии (см. раздел 8)
Каждое можно выключить. «Выключить все пуши» отключает всё по устройству.
Опрос состояния идёт раз в POLL_SEC; LIVE и приложение обновляются чаще.


4. LIVE-РЕЖИМ В ЧАТЕ
--------------------
Кнопка «📡 LIVE в чате»: сообщение обновляется на месте каждые 3 с.
  - заряд с полосой и кВт·ч, режим батареи
  - заряжается / отдаёт / простой (Вт)
  - сеть: берём из сети / отдаём в сеть / 0
  - выход EPS, мини-график мощности, прогноз работы, статистика за день, Wi-Fi
  - время последнего кадра, предупреждение если данные устарели
  Кнопки: ⏹ Стоп, ⏱ +10 мин, Устройство, Меню.
  Работает 10 минут и сам закрывается; также закрывается при нажатии любой другой кнопки.
  На время LIVE бот опрашивает батарею каждые ~3 с вместо 180.


5. MINI APP (ПРИЛОЖЕНИЕ В TELEGRAM)
-----------------------------------
Открывается кнопкой «📱 Приложение» (в меню, на экране устройства и как кнопка
меню бота). Работает через быстрый туннель cloudflared (https-адрес случайный,
меняется при перезапуске бота и сам подставляется в кнопки).

Вкладка LIVE (обновление каждые 2 с)
  - кольцо заряда, мощность и направление (заряд / отдача / простой)
  - сеть, EPS, статистика за день, Wi-Fi, режим
  - график мощности батареи за последние ~2 минуты
  - список всех показаний (с учётом скрытых полей)
  - баннеры: нет сети (и сколько), потеря связи, аномалии, код ошибки станции
  - 🔄 Обновить из облака (не чаще раза в 10 с)
  - выбор устройства, если их несколько
  - индикатор: LIVE / N с назад / нет кадра / нет связи

Вкладка История: графики заряда и мощности (батарея + сеть) за 1 ч, 6 ч, 24 ч, 7 дней.

Вкладка Отключения: 24 ч / 7 / 30 дней — число, суммарное и самое долгое время,
  % времени со светом, список отключений.

Вкладка Настройки (владелец): все настройки из раздела 6 + показ/скрытие каждого
  поля + тест уведомления, сброс к умолчанию, удаление устройства (с подтверждением).
  Зритель видит только переключатель «Мои уведомления».

Вкладка Доступ: кто смотрит устройство, добавить / убрать, уведомления для каждого;
  для админа ещё и управление пользователями бота.

Когда приложение закрыто или свёрнуто — опрос прекращается, через 20 с бот
возвращается к обычному режиму опроса.


6. НАСТРОЙКИ (ОДИНАКОВЫ В БОТЕ И В ПРИЛОЖЕНИИ)
----------------------------------------------
Хранятся по каждому устройству. Правила проверки значений одни на оба интерфейса.
  Уведомления
    - все пуши по устройству вкл/выкл
    - низкий заряд вкл/выкл; пороги, % (через запятую, 1…99)
    - «заряжена до 100%» вкл/выкл
    - перегрузка вкл/выкл; порог 80/90/95 %; предел, Вт (0 = авто)
    - потеря связи вкл/выкл; через 2/4/10/30 мин
    - прогноз времени работы вкл/выкл
    - детектор аномалий вкл/выкл
  Устройство
    - режим детекции сети: Авто / Online / Grid Вт
    - ёмкость батареи
  Показания: какие поля показывать на экране
  Действия: тест уведомления, сброс к умолчанию, удаление


7. ДОСТУП: ПОДЕЛИТЬСЯ УСТРОЙСТВОМ, РОЛИ
---------------------------------------
Роли: админ (первый пользователь или ADMIN_ID), пользователь (одобрен админом),
  ожидает / отклонён. Новый пользователь пишет боту — админу приходит заявка.

Поделиться устройством (владелец → другой пользователь бота):
  - в боте: «👥 Поделиться», в приложении: вкладка «Доступ»
  - зритель получает уведомление об открытии доступа
  - зритель видит: показания, LIVE, историю, отключения; получает алерты
    (если включены); может сам выключить свои уведомления
  - зритель НЕ может: менять настройки, удалять, слать тест, делиться дальше
  - владелец в любой момент закрывает доступ или переключает уведомления зрителя
  Делиться можно только с одобренными пользователями.


8. ДЕТЕКТОР АНОМАЛИЙ
--------------------
Раз в минуту живой кадр сохраняется в историю (14 дней). По ней ищутся:
  📶 слабый Wi-Fi (медиана за 10 мин хуже −80 dBm)
  🔌 станция тянет мощность в простое (в среднем > 60 Вт 15 мин)
  🪫 заряд уходит быстрее, чем объясняет мощность (утечка / сбой BMS / скрытая нагрузка)
  📉 скачок заряда (≥ 8 п.п. без мощности — обычно перекалибровка BMS)
  🔁 частое переключение режимов (≥ 6 смен за 10 мин — нестабильная сеть)
Одна и та же проблема не повторяется чаще раза в 6 часов. Показывается и баннером
в приложении.

----------------

  mqtt_live.py   живые данные по MQTT, расшифровка кадров
  hame_mqtt.py   вычисление идентификаторов топиков MQTT
  anomaly.py     детектор аномалий
  mqtt_certs/    сертификаты MQTT
  tools/         cloudflared.exe (туннель), pull_certs.py, mqtt_probe.py
  research/      разбор приложения Marstek, документация API
  _backups/      резервные копии перед правками
  .env           BOT_TOKEN, ADMIN_ID, POLL_SEC, WEBAPP, WEBAPP_PORT
  start_bot.bat  запуск: ставит окружение и зависимости, запускает бота


10. КОНФИГУРАЦИЯ (.env)
-----------------------
  BOT_TOKEN    токен от BotFather (обязателен)
  ADMIN_ID     Telegram ID админа (0 — первым админом станет первый написавший /start)
  POLL_SEC     интервал опроса облака, с (по умолчанию 180, минимум 10)
  WEBAPP       1 — включить Mini App, 0 — выключить (по умолчанию 1)
  WEBAPP_PORT  локальный порт сервера приложения (по умолчанию 8765)


11. БЕЗОПАСНОСТЬ
----------------
  - Mini App: вход только по подписанным данным Telegram (проверка HMAC токеном бота,
    срок действия 2 суток); отдельных паролей и ссылок с токенами нет
  - Любой запрос проверяет: пользователь одобрен, устройство его или ему открыто
  - Зритель не может менять и удалять; ввод настроек проверяется на сервере
  - Сервер слушает только 127.0.0.1, наружу — через туннель cloudflared
  - Данные в приложении не кешируются (no-store), имена экранируются в интерфейсе
  - Пароль Marstek хранится как MD5 (требование API облака), сообщение с ним удаляется
  - .env и data.db содержат секреты — не публикуйте и не отправляйте их


12. ОГРАНИЧЕНИЯ
---------------
  - Адрес туннеля случайный и меняется при каждом запуске бота. Постоянный адрес
    требует своего домена в Cloudflare.
  - Без запущенного бота приложение не работает (сервер внутри бота).
  - Зрителю нужно, чтобы владелец ПК/бота работал: данные идут через его бота.
  - Перегрузка проверяется раз в POLL_SEC, короткие пики между опросами не видны.
  - Мощности для Venus E 3.0 доступны только по MQTT; нужны сертификаты в mqtt_certs/.
  - История в приложении копится с момента запуска версии с детектором аномалий.
